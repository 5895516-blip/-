# Промо v2: что меняем ради продаж

## Почему v1 продаёт слабо (самопроверка)

1. **Нет крючка.** Первые 7.5 с в v1 — только частицы и текст. В ленте решение «смотреть или листать» принимается за 1–2 с, а работ в это время не видно.
2. **Работы мелкие.** Главный аргумент студии — сами ролики, а в v1 они идут небольшими экранами по ~2 с.
3. **Выгоды абстрактные.** «Быстро» и «Выгодно» говорит каждая студия. На сайте есть конкретика: ≈4 рабочих дня на ролик до минуты, сценарий/озвучка/музыка/липсинк/субтитры без доплат, форматы под любую площадку.
4. **Нет социального доказательства**, кроме «800+». На сайте есть отзывы и география клиентов.
5. **Нет повода действовать сейчас.** Финал «Обсудить проект» без оффера. На сайте есть оффер «−10% на первый проект, промокод NEURO10» и калькулятор «расчёт за минуту».
6. **Финал трудно превратить в заявку.** Нет QR-кода, контакты мелкие.
7. **Нет звукового дизайна.** На переходах не слышно ни свиста, ни ударов: монтаж «под бит» есть, но ощущается слабее.

## Сценарий v2 (сетка та же: 128 BPM, такт 1.875 с)

| Время | Сцена | Смысл |
|---|---|---|
| 0–5.6 | **Крючок.** Работы во весь кадр на 3D-призме, поворот на каждый такт: «Ни одной камеры» → «Ни одного актёра» → «Ни одной локации» | Цепляем работами с первого кадра |
| 5.6–7.5 | Призма разлетается на сотню 3D-осколков, они превращаются в золотые частицы и собирают нейросферу: «Это всё — нейросети» | Раскрытие |
| 7.5–9.4 | Объёмный логотип (3D-толщина, блик) | Бренд на дропе |
| 9.4–11.25 | Счётчик 0 → 800+ «проектов с 2022 года» | Доказательство |
| 11.25–13.1 | «≈ 4 рабочих дня на ролик до минуты» | Конкретная выгода |
| 13.1–15 | 3D-глобус из точек суши, на каждую долю дуги в страны клиентов с сайта | География = доверие |
| 15–22.5 | Спираль из экранов, каждый такт работа выезжает почти во весь кадр + направление | Показываем товар лицом |
| 22.5–26.25 | «Обычный продакшн»: 3D-карточки «Съёмочная группа / Аренда площадки / Актёры / Месяцы ожидания», зачёркиваются и рассыпаются на долю | Боль клиента |
| 26.25–30 | «А нужна только идея» → варп | Решение |
| 30–33.75 | 3D-трасса процесса: Идея и сценарий → Кадры → Голос и музыка → Монтаж | Снимаем страх «а как это работает» |
| 33.75–37.5 | Вокруг сферы облетают чипсы «Сценарий / Нейроозвучка / Музыка / Липсинк / Субтитры / Бренд»: «Всё включено — без доплат» | Ценность без скрытых платежей |
| 37.5–41.25 | Два отзыва с сайта на 3D-карточках | Социальное доказательство |
| 41.25–45 | Экран с работой меняет формат 16:9 → 9:16 → 1:1: «Под любую площадку» | Полезно SMM-заказчику |
| 45–52.5 | Купол из экранов вокруг камеры: «Ваш ролик может быть следующим» | Вовлечение |
| 52.5–60 | Оффер −10% / NEURO10, QR на сайт, «расчёт стоимости за 1 минуту», телефон / Telegram / WhatsApp | Повод и способ действовать сейчас |

Плюс звуковой слой: свисты на поворотах и вылетах экранов, удары на зачёркиваниях и вспышках (`music/make_sfx.py`).

## Что проверить заказчику
- Действует ли оффер «−10% на первый проект, NEURO10» (взят из калькулятора на сайте).
- Можно ли показывать отзывы и аватары с сайта в рекламе.
- Подписи направлений у работ (сопоставлены по смыслу).
