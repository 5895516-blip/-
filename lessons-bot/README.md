# Бот с уроками для Telegram

Бот выдаёт уроки людям, которые приходят из Instagram: человек нажимает «Старт», подписывается на твой канал и получает урок. Управлять им можно двумя способами: в браузере через панель (`/panel`) или прямо в Telegram (`/admin`).

## Что умеет

**Для учеников**

- `/start` — приветствие и список уроков кнопками.
- У каждого урока своя ссылка вида `https://t.me/твой_бот?start=lesson1`. Человек, пришедший по ней, сразу получает именно этот урок — эту ссылку и вставляй в ChatPlace.
- Обязательная подписка: пока человек не подписан на канал (или группу), вместо уроков он видит кнопку «Подписаться» и «✅ Я подписался». После подписки бот сам выдаёт тот урок, за которым человек пришёл.
- Урок — это ссылка (YouTube, Google-диск, презентация…), файл, видео, фото или текст.

**Панель в браузере (`/panel`)**

Отправь боту `/panel` — он пришлёт одноразовую ссылку для входа. Панель открывается с телефона и с компьютера.

- **Обзор** — сколько людей, график новых за 30 дней, какие уроки открывают, по каким ссылкам приходят, что сейчас отправляется.
- **Рассылки** — текст с картинкой и кнопкой, предпросмотр, «отправить тест себе», отправка сразу или в назначенное время, остановка и отмена, история с цифрами доставки. Можно писать не всем, а части людей: кто не открыл ни одного урока, кто открывал или не открывал конкретный урок, кто пришёл по конкретной ссылке, новым за последние дни. `{имя}` в тексте заменяется на имя человека.
- **Уроки** — добавить, изменить, скрыть, поменять порядок, скопировать ссылку, уведомить всех об уроке.
- **Автосообщения** — бот сам пишет каждому новому человеку через заданное время после старта (например, через день напомнить про следующий урок).
- **Люди** — список с поиском и выгрузкой в таблицу (CSV, открывается в Excel).
- **Настройки** — обязательная подписка, тексты бота, защита уроков от пересылки.

**В Telegram (`/admin`)** — то же самое основное, когда под рукой только телефон:

- **📚 Уроки** — добавить, изменить, скрыть, удалить, поменять порядок, получить ссылку на урок.
- **📢 Рассылка** — прислать любое сообщение всем пользователям (с предпросмотром и подтверждением).
- **📢 Уведомить всех об уроке** — кнопка в карточке урока: всем придёт «Новый урок» с кнопкой «Открыть».
- **🔔 Обязательная подписка** — на какие каналы/группы нужно подписаться.
- **📊 Статистика** — сколько людей, сколько новых, сколько раз открыт каждый урок, по каким ссылкам приходят.
- **✏️ Тексты** — приветствие и просьба подписаться.
- **⚙️ Настройки** — запрет пересылать и сохранять уроки.

## Запуск: 4 шага

Нужен только Python 3.9 или новее. Никаких библиотек ставить не надо.

**1. Создай бота.** В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username. Он пришлёт токен вида `123456:AAH...`.

**2. Впиши токен.** Скопируй файл `.env.example` в `.env` и вставь токен в строку `BOT_TOKEN=`.

**3. Запусти.** На Windows — двойной щелчок по файлу `start.bat`. На Mac и Linux:

```bash
python3 main.py
```

**4. Стань админом.** Отправь боту `/id` — он ответит твоим числом-ID. Впиши его в `.env` в строку `ADMIN_IDS=`, останови бота (Ctrl+C) и запусти снова. Теперь работают `/admin` и `/panel`.

## Первая настройка в Telegram

1. `/admin` → **➕ Добавить урок** → название → описание → сам материал (ссылка или файл). Бот покажет, как урок выглядит для ученика, и даст ссылку на него.
2. Чтобы включить обязательную подписку: добавь бота **администратором** в свой канал, затем `/admin` → **🔔 Обязательная подписка** → **➕ Добавить канал** → пришли `@username` канала или перешли любой пост из него.
3. Ссылку из карточки урока вставь в ChatPlace как кнопку/ссылку в автоответе.

> Свой «код» в ссылке можно задать самому (кнопка **🔗 Код ссылки**), например `reels5`. В статистике будет видно, сколько людей пришло по каждой ссылке.

## Чтобы бот работал круглосуточно

Бот работает, пока запущена программа, поэтому его надо держать на сервере (подойдёт самый дешёвый VPS с Linux). Скопируй папку `lessons-bot` на сервер вместе с файлом `.env` и выбери один из способов.

**Через Docker:**

```bash
docker compose up -d --build
```

**Без Docker (systemd):** открой файл `lessons-bot.service` — внутри три команды и путь, который надо поправить.

**Панель на сервере.** Впиши в `.env` адрес сервера: `PANEL_URL=http://АДРЕС_СЕРВЕРА:8080` — по нему бот будет присылать ссылку на команду `/panel`. Порт 8080 должен быть открыт. В панель попадают только те, чей ID вписан в `ADMIN_IDS`: ссылка для входа одноразовая и живёт 10 минут.

> Адрес вида `http://…` передаёт данные без шифрования. Для постоянной работы лучше подключить домен с `https://` (например, через Caddy или nginx) и вписать его в `PANEL_URL`. Панель не нужна — поставь `PANEL_PORT=0`.

Все данные (уроки, пользователи, рассылки, настройки) лежат в одном файле `data/bot.db`. Чтобы сделать резервную копию или переехать на другой сервер — просто скопируй этот файл.

## Если что-то не так

| Что видишь | Что делать |
| --- | --- |
| «Не задан BOT_TOKEN» | Нет файла `.env` или в нём не вписан токен. |
| «Telegram не принял BOT_TOKEN (401)» | Токен скопирован с ошибкой — возьми его заново у @BotFather. |
| «Бот уже запущен где-то ещё» | Запущены две копии с одним токеном. Оставь одну. |
| `/admin` или `/panel` не отвечает | Твой ID не вписан в `ADMIN_IDS`, или бот не перезапущен после правки `.env`. |
| Ссылка из `/panel` не открывается | В `PANEL_URL` должен быть адрес, по которому сервер виден из интернета, а порт панели — открыт. |
| «Ссылка устарела» при входе | Ссылка одноразовая и живёт 10 минут. Отправь боту `/panel` ещё раз. |
| «Не удалось запустить панель на порту…» | Порт занят другой программой. Поменяй `PANEL_PORT` в `.env`. |
| «Не могу проверить подписку…» | Бота убрали из администраторов канала. Верни его — проверка заработает сама. |

## Для разработчика

- `main.py` — запуск, `app.py` — логика бота и очередь рассылок, `db.py` — SQLite, `tg.py` — клиент Bot API, `config.py` — настройки.
- `panel.py` — HTTP-сервер и API панели, `panel/` — её страница (HTML, CSS, JS без сборки и внешних библиотек).
- Только стандартная библиотека Python; обновления получаются через long polling.
- Рассылки хранятся в базе: отложенные отправляются по времени, прерванная перезапуском продолжается с того же получателя.
- Тесты гоняют бота и панель на локальной имитации сервера Telegram:

```bash
python3 -m unittest discover -s tests -v
```
