# Бот с уроками для Telegram

Бот выдаёт уроки людям, которые приходят из Instagram: человек нажимает «Старт», подписывается на твой канал и получает урок. Всё управление — прямо в Telegram, через панель `/admin`.

## Что умеет

**Для учеников**

- `/start` — приветствие и список уроков кнопками.
- У каждого урока своя ссылка вида `https://t.me/твой_бот?start=lesson1`. Человек, пришедший по ней, сразу получает именно этот урок — эту ссылку и вставляй в ChatPlace.
- Обязательная подписка: пока человек не подписан на канал (или группу), вместо уроков он видит кнопку «Подписаться» и «✅ Я подписался». После подписки бот сам выдаёт тот урок, за которым человек пришёл.
- Урок — это ссылка (YouTube, Google-диск, презентация…), файл, видео, фото или текст.

**Для тебя (`/admin`)**

- **📚 Уроки** — добавить, изменить, скрыть, удалить, поменять порядок, получить ссылку на урок.
- **📢 Рассылка** — прислать любое сообщение всем пользователям (с предпросмотром и подтверждением).
- **📢 Уведомить всех об уроке** — кнопка в карточке урока: всем придёт «Новый урок» с кнопкой «Открыть».
- **🔔 Обязательная подписка** — на какие каналы/группы нужно подписаться.
- **📊 Статистика** — сколько людей, сколько новых, сколько раз открыт каждый урок, по каким ссылкам приходят.
- **✏️ Тексты** — приветствие и просьба подписаться.
- **⚙️ Настройки** — запрет пересылать и сохранять уроки.

## Запуск: 4 шага

Нужен только Python 3.9 или новее. Никаких библиотек ставить не надо.

**1. Создай бота.** В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username. Он пришлёт токен вида `123456:AAH...`.

**2. Впиши токен.** Скопируй файл `.env.example` в `.env` и вставь токен в строку `BOT_TOKEN=`.

**3. Запусти:**

```bash
python3 main.py
```

**4. Стань админом.** Отправь боту `/id` — он ответит твоим числом-ID. Впиши его в `.env` в строку `ADMIN_IDS=`, останови бота (Ctrl+C) и запусти снова. Теперь работает `/admin`.

## Первая настройка в Telegram

1. `/admin` → **➕ Добавить урок** → название → описание → сам материал (ссылка или файл). Бот покажет, как урок выглядит для ученика, и даст ссылку на него.
2. Чтобы включить обязательную подписку: добавь бота **администратором** в свой канал, затем `/admin` → **🔔 Обязательная подписка** → **➕ Добавить канал** → пришли `@username` канала или перешли любой пост из него.
3. Ссылку из карточки урока вставь в ChatPlace как кнопку/ссылку в автоответе.

> Свой «код» в ссылке можно задать самому (кнопка **🔗 Код ссылки**), например `reels5`. В статистике будет видно, сколько людей пришло по каждой ссылке.

## Чтобы бот работал круглосуточно

Бот работает, пока запущена программа, поэтому его надо держать на сервере (подойдёт самый дешёвый VPS с Linux). Скопируй папку `lessons-bot` на сервер вместе с файлом `.env` и выбери один из способов.

**Через Docker:**

```bash
docker compose up -d --build
```

**Без Docker (systemd):** открой файл `lessons-bot.service` — внутри три команды и путь, который надо поправить.

Все данные (уроки, пользователи, настройки) лежат в одном файле `data/bot.db`. Чтобы сделать резервную копию или переехать на другой сервер — просто скопируй этот файл.

## Если что-то не так

| Что видишь | Что делать |
| --- | --- |
| «Не задан BOT_TOKEN» | Нет файла `.env` или в нём не вписан токен. |
| «Telegram не принял BOT_TOKEN (401)» | Токен скопирован с ошибкой — возьми его заново у @BotFather. |
| «Бот уже запущен где-то ещё» | Запущены две копии с одним токеном. Оставь одну. |
| `/admin` не отвечает | Твой ID не вписан в `ADMIN_IDS`, или бот не перезапущен после правки `.env`. |
| «Не могу проверить подписку…» | Бота убрали из администраторов канала. Верни его — проверка заработает сама. |

## Для разработчика

- `main.py` — запуск, `app.py` — вся логика, `db.py` — SQLite, `tg.py` — клиент Bot API, `config.py` — настройки.
- Только стандартная библиотека Python; обновления получаются через long polling.
- Тесты гоняют бота на локальной имитации сервера Telegram:

```bash
python3 -m unittest discover -s tests -v
```
