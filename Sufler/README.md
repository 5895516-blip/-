# Суфлёр

Телесуфлёр для iPhone, который показывает текст в плавающем окне **поверх обычной Камеры**
(и любого другого приложения — Instagram, TikTok, Zoom). Окно двигается пальцем, растягивается
двумя, а в запись не попадает: его видите только вы.

## Что умеет

- Список текстов и редактор: вставка из буфера, загрузка из `.txt`.
- Плавная прокрутка с заданной скоростью в словах в минуту — приложение сразу показывает,
  сколько займёт весь текст.
- Текст стартует сам: когда вы уходите в Камеру, в окне идёт обратный отсчёт
  (3, 5, 10 или 15 секунд), чтобы успеть нажать запись и встать в кадр.
- Пауза и старт стуком по задней крышке телефона — через «Команды» и «Касание задней панели»
  (инструкция есть в приложении).
- Жёлтая стрелка у строки, которую читаете; прочитанные строки приглушаются.
- Размер шрифта, цвет, выравнивание, форма окна (16:9, 4:3, 1:1, 3:4).
- Горизонтальная съёмка: системная Камера не поворачивает чужие окна, поэтому текст
  поворачивается внутри окна сам — выберите «Гориз.» в настройках.
- Ремарки в квадратных скобках (`[пауза]`) подсвечиваются и не считаются словами.

### Два типа окна

iOS по-разному обращается с плавающими окнами, когда другое приложение начинает запись видео,
поэтому тип окна можно выбрать:

| Тип | Что это | Особенности |
|---|---|---|
| **Для Камеры** (по умолчанию) | Окно как у видеозвонка | iOS не гасит его во время записи. Кнопок внутри нет. |
| **С кнопками** | Окно как у видео | Внутри ▶/⏸ и кнопки «15» (скорость и абзацы), но при начале записи iOS часто ставит его на паузу и прячет к краю экрана. |

## Как снимать

1. Откройте текст и нажмите «Запустить поверх Камеры». Появится окно с текстом, следом откроется Камера.
2. В Камере выберите «Видео». Окно перетащите ближе к объективу, двумя пальцами растяните.
3. Начните запись. В окне идёт отсчёт — после него текст поедет сам.

Если Камера не открылась сама — смахните вверх и откройте её как обычно, окно останется поверх.

Внизу экрана запуска есть строка «Прошлый запуск окна»: сколько секунд окно работало и сколько
кадров нарисовало в фоне. Если что-то пошло не так, эта строка помогает понять причину.

## Установка на iPhone

Нужны Mac с Xcode и кабель. Подойдёт бесплатный Apple ID.

Сначала скачайте проект. В Терминале:

```bash
git clone -b claude/practical-gauss-wo4ftg https://github.com/5895516-blip/-.git sufler
```

### Быстрый способ — одна команда

Подключите iPhone кабелем, разблокируйте его и выполните:

```bash
bash sufler/Sufler/tools/install.sh
```

Скрипт сам найдёт телефон и ваш Apple ID из Xcode, соберёт приложение и установит его.
Если что-то пойдёт не так, он напишет причину — тогда воспользуйтесь способом ниже.

### Через окно Xcode

1. Откройте `sufler/Sufler/Sufler.xcodeproj`.
2. Слева выберите проект **Sufler** → цель **Sufler** → вкладка **Signing & Capabilities** →
   в поле **Team** выберите свой Apple ID (Personal Team).
   Если Xcode пишет, что идентификатор занят, поменяйте в **Bundle Identifier** последнее слово на любое своё.
3. Подключите iPhone кабелем, разблокируйте его и выберите его вверху окна Xcode как устройство для запуска.
4. Нажмите ▶ (Run). Приложение соберётся и установится.

### Что важно знать про бесплатный Apple ID

- На телефоне одновременно может стоять не больше трёх таких приложений. Если их уже три —
  удалите одно с телефона перед установкой.
- Приложение работает 7 дней, потом его нужно установить заново тем же способом.
  Тексты при этом сохраняются, если приложение не удалять с телефона.
- При первом запуске iPhone может попросить подтвердить разработчика:
  Настройки → Основные → VPN и управление устройством.

## Для разработки

- iOS 16.4 и новее, Swift 5, SwiftUI. Сторонних библиотек нет.
- Плавающее окно — это «Картинка в картинке» (`FloatingPrompter`). Окно «Для Камеры» — видеозвонок
  с обычным видом внутри (`FloatingCanvasView`); окно «С кнопками» получает кадры через
  `AVSampleBufferDisplayLayer`. Рисует оба один и тот же `FloatingFrameRenderer`.
- Пока окно открыто, приложение играет тишину (`KeepAlive`), иначе iOS усыпит его в фоне.
- Положение текста считается от времени (`ScrollClock`), а не прибавляется по кадрам, поэтому
  прокрутка ровная при любой частоте кадров.
- После добавления или удаления файлов пересоберите проект Xcode:
  ```bash
  python3 Sufler/tools/gen_xcodeproj.py
  ```
- Тесты:
  ```bash
  xcodebuild test -project Sufler/Sufler.xcodeproj -scheme Sufler -destination 'platform=iOS Simulator,name=iPhone 17'
  ```
